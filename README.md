# AI in Biology: A Self-Paced Introduction

A self-paced, four-part Google Colab notebook series introducing machine learning fundamentals (supervised, unsupervised, and a taste of reinforcement learning) to Minor in Bioinformatics students, built around classic datasets and framed throughout with biological applications: genomics, transcriptomics, proteomics, and drug discovery.

Developed by **Jayesh M. Bhagat**, Assistant Professor, Department of Life Sciences, SBAS, Somaiya Vidyavihar University, with structural suggestions from students in the course, one of whom suggested this material be made public here.

No prior AI/ML background is assumed. Basic Python and pandas familiarity is helpful but not required, Module 0 covers the essentials.

## What each session covers

**Session 1–2 (Modules 0–3):** the AI/ML/DL/NLP landscape, exploratory data analysis, data preprocessing (cleaning, normalization, a full missing-values decision framework), dimensionality reduction with PCA, and bonus interactive visualizations.

**Session 3 (Modules 4–5):** classification with logistic regression, k-NN, decision trees, SVM, and Random Forest, model evaluation beyond accuracy (sensitivity, specificity, precision, recall, F1, ROC/AUC), and cross-validation.

**Session 4 (Modules 6–7):** regression and overfitting, K-means and hierarchical clustering, evaluating clusters without ground-truth labels via silhouette score, and a t-SNE bonus.

**Session 5–6 (Modules 8–12):** a conceptual tour of neural network architectures (MLP, CNN, RNN, DBN) with a hands-on MLP classifier, a taste of NLP via TF-IDF text classification, a taste of reinforcement learning via a multi-armed bandit, ethical and societal considerations in AI for biology, and an independent capstone project.

## How this works, mechanically

GitHub hosts and version-controls these files, but does not run them. Clicking a Colab badge above opens a live, private, editable Python session for *you*, pulling the notebook's content directly from this repository. You can run every cell, edit anything, and experiment freely, your changes exist only in your own browser session and are never written back to this repository.

To keep your work, use Colab's **File → Save a copy in Drive**. This saves a personal copy to your own Google Drive, which you can then continue editing independently. The copy here on GitHub always stays clean for the next person who opens it.
